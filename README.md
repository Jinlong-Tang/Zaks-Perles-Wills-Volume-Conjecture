# Maximum-volume-lattice-polytopes-with-k-interior-lattice-points
We prove that for $d\ge4$ and $k\ge1$, a $d$-dimensional lattice polytope with $k$ interior lattice points has normalized volume at most $(k+1)(s_d-1)^2$, where $s_d$ is the $d$th Sylvester number. Equality holds if and only if the polytope is affinely unimodularly equivalent to the Sylvester simplex.
